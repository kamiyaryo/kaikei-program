# 営業売上計算プログラム

## 概要

pythonの基礎学習を目的として制作した売上計算プログラムです。
契約したプランと契約件数を入力することで、契約ごとの売上金額、合計売上、条件に応じたインセンティブを計算できます。

## 主な機能

### 1. 営業プランの選択
以下の3つのプランから選択できます。

| プラン | 単価 |
|---|---:|
| 上位プラン | 1,200,000円 |
| 中位プラン | 900,000円 |
| 下位プラン | 600,000円 |

### 2. 契約件数・売上金額の計算
選択したプランの単価と契約件数を掛け合わせ、売上金額を計算します。

### 3. 複数契約の集計
複数の契約情報を入力でき、入力した契約履歴と合計売上を表示します。

### 4. インセンティブ計算
合計売上が3,000,000円以上の場合、合計売上の10%をインセンティブとして計算します。

### 5. 入力エラーへの対応
- 数字以外が入力された場合、エラーメッセージを表示
- 存在しないプラン番号が入力された場合、再入力を受け付け
- 契約件数が0以下の場合、再入力を受け付け

## 実行例

```text
1: 上位プラン 1,200,000円
2: 中位プラン 900,000円
3: 下位プラン 600,000円
0: 入力終了

プラン番号を入力してください: 1
選択: 上位プラン (1,200,000円)
契約件数を入力してください: 2
上位プラン 1,200,000円 x 2件 = 2,400,000円

プラン番号を入力してください: 2
選択: 中位プラン (900,000円)
契約件数を入力してください: 1
中位プラン 900,000円 x 1件 = 900,000円

プラン番号を入力してください: 0

-- 営業売上集計 --
上位プラン 1,200,000円 x 2件 = 2,400,000円
中位プラン 900,000円 x 1件 = 900,000円
合計売上: 3,300,000円
インセンティブ: 330,000円
```

## 使用技術

- Python 3
- Git / GitHub（ソースコードのバージョン管理）

Pythonの標準機能のみを使用しており、外部ライブラリは使用していません。

## 実行方法

1. Python 3がインストールされた環境を用意します。
2. 本リポジトリをダウンロード、またはクローンします。
3. ターミナルで `kaikei.py` があるディレクトリに移動します。
4. 以下のコマンドを実行します。

```bash
python3 kaikei.py
```

## 学習・実装した内容

本プログラムの制作を通じて、以下のPythonの基礎知識を実践しました。

| 学習項目 | 実装内容 |
|---|---|
| 辞書（dict） | プラン番号とプラン情報の管理 |
| タプル（tuple） | プラン名と単価の保持 |
| リスト（list） | 契約履歴の保存 |
| for文 | プラン一覧・契約履歴の表示 |
| while文 | プラン選択と契約件数の繰り返し入力 |
| if文 | プラン番号・契約件数・売上条件の判定 |
| break / continue | 繰り返し処理の制御 |
| try / except | 不正な入力値への対応 |
| f文字列 | 金額のカンマ区切り表示 |
